# Dependency/API verification

Verified on 2026-09-14 using official documentation and the installed pinned APIs.

- [faster-whisper upstream documentation](https://github.com/SYSTRAN/faster-whisper): direct PyAV decoding without a separate FFmpeg CLI; batched pipeline; model loading; CPU int8; CUDA 12 cuBLAS and cuDNN 9 runtime requirements. Installed 1.2.1 signatures were inspected for `initial_prompt`, `condition_on_previous_text`, `without_timestamps`, `batch_size`, and `local_files_only` support. `download_model` supports a pinned revision and a project-local cache.
- [CTranslate2 installation](https://opennmt.net/CTranslate2/installation.html): native runtime/platform requirements. CTranslate2 4.6.0 was tested on Windows with the pinned NVIDIA libraries. It imports `pkg_resources`; setuptools 84 failed at import, and setuptools 80.9.0 resolved that incompatibility. The known deprecation warning remains harmless with this lock.
- [PyMuPDF OCR](https://pymupdf.readthedocs.io/en/latest/recipes-ocr.html) and [Page API](https://pymupdf.readthedocs.io/en/latest/page.html#Page.get_textpage_ocr): OCR text pages, language data, and mixed text/image extraction. The implementation reuses each OCR text page in sorted text extraction. Tests exercised selectable, scanned, and mixed pages with English language data and inspected a rendered fixture.
- [python-docx Document API](https://python-docx.readthedocs.io/en/latest/api/document.html): `iter_inner_content()` yields body paragraphs and tables in document order. This does not provide Word pagination or all ancillary XML content.
- [EbookLib tutorial](https://docs.sourcefabric.org/projects/ebooklib/en/latest/tutorial.html): read EPUB, metadata/items, and book spine. A reversed archive-order fixture validated spine-based reading order.
- [Calibre ebook-convert](https://manual.calibre-ebook.com/generated/en/ebook-convert.html) and [portable installation](https://calibre-ebook.com/download_portable): local conversion command and automated installation argument. Actual EPUB→MOBI→EPUB conversion was exercised with Calibre 9.14.0.
- [NVIDIA Windows cuDNN installation](https://docs.nvidia.com/deeplearning/cudnn/installation/latest/windows.html): Windows runtime archives. Download pins/checksums were taken from NVIDIA's [CUDA 12.8.1 redistribution manifest](https://developer.download.nvidia.com/compute/cuda/redist/redistrib_12.8.1.json) and [cuDNN 9.10.2 redistribution manifest](https://developer.download.nvidia.com/compute/cudnn/redist/redistrib_9.10.2.json).
- [Tesseract English language data](https://github.com/tesseract-ocr/tessdata_fast): pinned commit and downloaded SHA-256 are recorded in `scripts/install_resources.py`.

`requirements.in` records direct dependency decisions; `requirements.lock.txt` pins the entire tested Python environment. Model commits and native resource checksums are separately pinned. The desktop application itself does not use an OpenAI API or any other hosted inference API.
